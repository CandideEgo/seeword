## 如何查一项

用文件路径在分册或 inventory.json 搜索。先看“职责”，再看“直接使用者”（谁会受影响）、“直接依赖”（它会影响什么）、“配置/隐式入口”。符号名保留原文，方便在编辑器搜索，业务含义用中文解释。

测试文件中的英文用例名和迁移中的原始标题是证据锚点，不是让新人只凭文件名猜功能。图标/媒体、revision、空包标记等即使没有 import 边，也有框架/发行/数据兼容意义。

导入图不是运行时调用图：函数内惰性 import 已纳入，TS 动态 import 已纳入；反射、生成 URL、队列消息与远端 NSSM 不能仅靠 AST 穷尽。未证明无消费者的文件保留并说明边界。
