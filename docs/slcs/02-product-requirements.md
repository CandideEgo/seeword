# 02 Product Requirements · 产品需求

本页描述 SLCS 试点的目标体验。功能状态、上线顺序和回退条件见路线图。[实施路线](06-implementation-roadmap.md)

## 贡献与站内目录

- 贡献者在本地校验学习包后，通过 Git PR 提交包和审核依据。校验失败时能定位出错字段。维护者可查看候选内容和依据，完成审核后显式发布。权限与处置规则见 [社区治理](05-community-governance.md)。
- 登录用户从小目录进入已发布课程。课程入口打开当前版，学习历史和原句链接打开记录时的修订。课程撤回当前版后从目录隐藏。打开撤回的历史修订时显示「材料已不可用」，已取得的学习进度和复习状态仍可见。[系统架构](03-system-architecture.md)

## 看视频、读字幕与查词

| 场景           | 学习者可完成的操作                                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 原站外链       | 站内阅读英中字幕，点重点词看语境释义并定位到原句，查看时间区间后从明确入口打开原视频。同步控件只在取得播放时间时出现。     |
| 官方嵌入       | 播放器时钟驱动当前字幕与词级高亮。点击字幕可跳到原句。嵌入失败时显示播放状态和原站入口，获准展示的双语字幕与释义仍可阅读。 |
| 词缺少时间对齐 | 点词仍可看释义和原句，播放定位使用整句时间区间。                                                                           |

## 站内导师与自带 Agent

- 站内学习者可选中重点词询问「这里是什么意思」。对获准向模型披露的材料，导师结合当前修订中的原句作答并给出可回跳的引用。仅获准站内展示时，用户仍可查阅包内释义。恢复对话时，已撤回的引用显示不可用。[社区治理](05-community-governance.md)
- 独立客户端可离线读取同一学习包，显示双语字幕、语境词义和原句位置。自带 Agent 的用户可选定本地包，用 CLI 查看结构化结果，或在自己的 Agent 宿主中连接 stdio MCP。用户在宿主配置自己的模型 API，询问同一词义时可获得原句出处。宿主的模型调用失败时，本地读取和查词仍可使用。[系统架构](03-system-architecture.md)
- 本地包不合法时，读取入口返回可定位的诊断。查不到指定段或词时，明确报告该锚点不可用，用户可回到所选包重新定位。[SLCS 规范](README.md)

## 收词与复习

学习者从不同材料收录同一个词时，词条保留各处原句的入口，复习进度仍归同一词条。用户从复习历史回看时，应能打开相应材料修订。旧锚点失效或材料撤回时，入口显示不可用，词条与复习记录仍可使用。一次复习即使重试提交，历史也只显示一次。[实施路线](06-implementation-roadmap.md)

## 页面与入口

试点复用现有登录边界与用户壳，新增入口挂在独立路径下，不改旧观看路由。路径名为提案，实施阶段可按现有路由习惯调整；状态列区分已存在与待实施。

| 页面           | 路径                                    | 角色             | 状态         |
| -------------- | --------------------------------------- | ---------------- | ------------ |
| 课程目录       | `/lessons`                              | 登录学习者       | 待实施       |
| 学习页         | `/lessons/[lessonId]`                   | 登录学习者       | 待实施       |
| 材料审核与发布 | `/admin/lessons`                        | 维护者           | 待实施       |
| 旧观看页       | `/watch/[id]`、`/watch/[id]/transcript` | 学习者为既有入口 | 已存在，保留 |

## 主要流程

- **贡献到发布**：本地校验 → 公开 PR → CI 校验 → 维护者按用途审核 → 导入候选修订 → 显式发布 → 目录可见。失败停在对应环节，候选版不进目录。
- **学习**：目录 → 学习页 → 播放或外链 → 选词查义 → 回到原句 → 收词 → 复习。历史与原句链接按记录时的修订解析。
- **外部消费**：本地包 → CLI 读结构 → 宿主连接 stdio MCP → 用自己的模型 API 提问 → 引用回到原句。

## 交互状态

学习页需覆盖加载、材料撤回、锚点失效与嵌入失败四类状态，外加入口配置错误时对包内非法内容的可定位诊断。空白与错误态不得用假数据填充，也不得把撤回材料的正文、字幕或词义留在页面上。状态口径与 [社区治理](05-community-governance.md) 的撤回规则一致。
