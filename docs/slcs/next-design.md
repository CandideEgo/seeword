# SeeWord 开放视频学习后续设计

SLCS v0.1 已有 JSON 规范、离线校验器、维基文库外链参考包和 V2 只读材料投影。视频发布、学习页和导师接入待实施。先跑通贡献、审核、发布与撤回，再验证两种观看模式，最后让导师与复习引用同一份材料。 [SLCS 文件契约](README.md) · [V2 接口契约](../../refactor-blueprint/docs/contracts.md)

首批在现有站点内提供小目录，沿用登录边界和 Git PR 贡献方式。具体嵌入样本在观看阶段确定，API 路径与表结构在对应功能开工时确定，匿名访问随公开目录一并评估。

## 第一阶段 · 贡献、发布与撤回

- **进入条件**　学习包通过离线校验。发起公开 PR 前，贡献者逐项核对字幕、译文、词汇和署名信息是否允许公开再分发，并随包提供依据。仓库保存学习数据和原片链接，媒体由原站提供。Git 历史和第三方副本各有独立的生命周期。
- **交付物**　提供贡献示例和离线命令，CI 调用同一个校验器并报告出错字段。维护者在站内发布前核对原文、译文、词汇锚点、站内展示权及适用的嵌入条件，按原视频、字幕、译文和词汇记录审核依据。审核通过的提交可导入为候选版，由维护者显式发布并切换当前版本。
- **修订与可见性**　`lesson_id` 标识同一课，内容指纹用于重复导入去重，不可变修订标识固定一次发布和后续学习引用。视频通过独立适配进入 V2 材料层，参考现有审核和操作回执设计。站内消费者统一解析修订可见性。撤回后停止提供该修订的正文、字幕和词汇语境，并使关联缓存失效。历史记录保留引用和学习状态，打开时显示材料已不可用。 [V2 材料域设计](../../refactor-blueprint/docs/architecture.md#2-模块与数据归属)
- **验收证据**　记录一次从 Git PR 到审核、导入、发布和撤回的演练。提交无效包时 CI 报出字段路径。相同包重复导入返回同一候选版，候选版在发布前对学习者不可见，发布失败后当前版本仍可读。发布新修订后通过材料读取入口核对历史引用仍指向原修订，撤回该修订后验证已有缓存也无法返回学习内容。

## 第二阶段 · 先验收外链，再验收官方嵌入

两种模式都从第一阶段的可见性入口读取已发布修订，并复用现有字幕交互。官方嵌入复用现有 YouTube 播放适配器。保留逐段听审记录和两种模式的浏览器走查证据，另用旧链接验证发布新版后仍定位到原修订、撤回原修订后显示不可用。 [维基文库参考包](examples/welcome-to-wikisource.json) · [YouTube 播放适配器](../../frontend/src/lib/youtubePlayer.ts)

| 模式 | 进入条件 | 交付物与验收证据 |
| --- | --- | --- |
| 原站外链 | 维基文库参考包完成逐段听审和发布审核。 | 学习者可在站内阅读双语字幕、点击重点词查看语境释义并定位原句，再从明确的入口打开原片。页面只在取得播放时间时展示同步控件。 |
| 官方嵌入 | 外链走查通过，另有一份已核对授权和嵌入条件的 YouTube 样本。 | 播放时钟驱动双语字幕与词级高亮，点击字幕可跳到原句。未对齐的重点词可查看释义并定位整句。人为触发嵌入失败后，页面提示播放状态并提供原片链接，获准展示的学习数据仍可阅读。 |

## 第三阶段 · 导师引用原句

- **进入条件**　两种观看模式验收通过，且所用材料已单独核对可向模型披露的范围。
- **交付物**　学习者选中重点词，导师从观看页所用的同一份已发布修订读取获准披露的字幕和词汇语境，解释该词在原句里的意思。回复引用带上材料类型、修订、段 ID 和词 ID，可回到原句。恢复历史时按当前权限重新核对修订可见性。 [V2 教学组件与动作方向](../../refactor-blueprint/docs/agent-plan.md)
- **验收证据**　记录一次选词、释义和回跳，并核对引用的修订与观看页一致。用可站内展示但未获准向模型披露的材料验证模型请求未携带该语境。撤回后恢复历史，验证引用显示不可用，且历史投影与缓存停止提供撤回的语境。

## 第四阶段 · 多来源收词与复习

- **进入条件**　导师引用和撤回验证通过，V2 P04 的词汇与复习依赖就绪。 [V2 实施主线](../../refactor-blueprint/docs/execution.md#当前实施主线)
- **交付物**　复用现有收词入口，同一词条保留在不同材料中的出现记录。新版字幕沿用未改动的段 ID 和词 ID。无法确认的旧锚点标为失效，由编辑核对后再迁移。跨来源复习、逐次日志和调度按 P04 验收推进。
- **验收证据**　从两份材料收录同一个词，核对两处语境分别保留并可定位。更新字幕后核对旧锚点的保留或失效状态，重复提交同一次复习时核对只记一条事实。

站内读取、权限和撤回验证稳定后，再评估公开目录、独立内容仓库、外部 Agent 读取和多语种扩展。贡献者工具优先支持已授权素材的导出、校验和预览。
