## 已知陷阱

写给下一个接手的人，都是实测过的，不要重新踩：

- **Windows 上每个 Python 进程都要 `PYTHONUTF8=1`**，否则读 UTF-8 的 `.env` 直接 `UnicodeDecodeError: 'gbk'`。
- **`python -m app.slcs schema` 的输出经 shell 管道会转 CRLF**，别用字节 diff 判等，用 JSON 比较。
- **本机 DNS 代理把域名解析到 `198.18.0.x`**，`is_private` 为真，会让 URL 护栏把合法域名判成内网。判断护栏行为前先看 `_resolve_ips` 返回什么。
- **`_is_blocked_ip` 漏 CGNAT**（`100.100.100.200` 不被拦）；SLCS 校验器本身也不拒绝私网与回环 `source_url`。将来若服务端要解引用包内 URL，这半必须重写。
- **`mediaUrl()` 的 token 分支先于绝对 URL 分支**：`mediaUrl(thirdPartyUrl, {withToken: true})` 会把 JWT 拼到第三方主机。课程深链只写 `revision` / `segment` / `token` 三个参数，不带任何媒体 token（`lessons.test.ts` 守着）。
- **`publicError` 会吃掉 SLCS 的字段路径诊断**：`createApiClient` 现在把结构化 `detail` 留在 `ApiClientError.detail` 上，管理端导入错误按 `{path, message}` 渲染；其它调用点仍可能把它拍平成 `"; "` 串。
- **`_VIDEO_ACCESS_CACHE` 是进程内 60s 且下架不清**，多 worker 各有窗口。它只服务旧视频链路；课程读取每次都查库，撤回即时生效。
- **`backend/` 下跑 `pytest slcs_tests` 会 skip**：那套测试要求先装发行 wheel（CI 里就是这么做的）。装好后用 `-o addopts= -o pythonpath=` 才能避开 `backend/pytest.ini` 把源码树遮到 wheel 前面。

## 怎么复验

在 `backend/` 下，带 `PYTHONUTF8=1`：

```sh
.venv/Scripts/python.exe -m app.slcs validate ../docs/slcs/examples/welcome-to-wikisource.json
.venv/Scripts/python.exe -m pytest tests/test_slcs.py tests/test_slcs_lessons.py tests/test_lesson_progress.py \
  tests/test_lesson_learning.py tests/test_lessons_http.py -q
.venv/Scripts/python.exe -m app.slcs schema   # 与 docs/slcs/schema.json 做 JSON 结构比较
```

课程用例的 PostgreSQL 腿要设 `PG_TEST_URL`（指向一个已迁移到 head 的库）；不设就只跑 SQLite。

独立发行包（在 `backend/` 下，先有任意 Python 3.12 环境）：

```sh
.venv/Scripts/python.exe ../backend/scripts/build_slcs_release.py --out ../dist/slcs-v0.1.0 --wheel
.venv/Scripts/python.exe -m pip wheel --no-deps --wheel-dir /tmp/wheels ./slcs
```

发行树的测试要在仓库外、装了该 wheel 的环境里跑（见 `docs/slcs/README.md`）。

在 `frontend/` 下：

```sh
npx vitest run src/lib/lessons.test.ts src/lib/subtitleFollow.test.ts src/lib/teaching.test.ts \
  src/lib/teachingStream.test.ts src/lib/transcriptDoc.test.ts src/lib/watchEntry.test.ts \
  src/lib/watchTime.test.ts src/lib/watchWordHighlight.test.ts
```

在仓库根：

```sh
npx --prefix frontend prettier --check "docs/slcs/*.md"
```
