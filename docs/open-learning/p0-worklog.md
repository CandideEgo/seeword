## 1. 本轮评审记录：接受到哪里

按用户本轮指示，将[开发方案大纲 v0.2](../seeword-open-source-development-outline-2026-11-13.md)接受为 **P0 的讨论与工作基线，仅此而已**。

本轮允许的工作是拆分文档、核对已有事实、盘点历史贡献与依赖，以及建立已有候选材料来源台账。它不批准许可证、贡献授权机制、目标学习者、试点数值、接口或生产放行。

- 不改根许可，不接收新的外部贡献，不对外承诺接口。
- 不联系历史贡献者或潜在学习者，不替用户征询外部意见；需要外部接触时另行获得授权。
- 不启动后续阶段开发、内容生产、正式招募、迁移或部署。
- 当前为同一助手整理和自核，不宣称独立审查、独立接入或学习者验收；责任角色可兼任，但尚未指定人员的角色仍记待定。

首次 P0 状态检查日暂定为 **2026-11-20（北京时间）**：只看三项阻塞决策、D05 输入与实际资源，记录“谁需要决定、缺什么证据、下一步是什么”，不靠继续扩写文档延长 P0。这个日期只是工作检查点，未创建自动提醒或后台任务，须在后续实际会话中复核。

## 3. 事实核对

### Astryx

接入记录确认实际使用 `@astryxdesign/core@0.7.15`、`@astryxdesign/theme-neutral@0.7.15` 和 StyleX，词汇页试点见[原验收记录](../evidence/astryx-integration/acceptance.md)。它只证明实际接入范围，不单独证明上游归属。

上游归属另对照本地下载的固定提交 `07c77c0087b719858a6d36795d454a7307c8a0ac` 的 README：Overview 明确说明源自 Meta，开头说明基于 React 19+ 与 StyleX。对应[固定提交原页](https://github.com/meta/astryx/blob/07c77c0087b719858a6d36795d454a7307c8a0ac/README.md)。本轮只读本地源码副本，没有执行下载物的脚本，也未在线重新抓取上游。

因此大纲调整为“Meta 的开源设计系统，基于 React 19+ 和 StyleX”。正式安装版本认接入记录与锁文件，不拿参考仓库主干替代发布包事实。暂缓的人工复验仍未完成，本轮没有补做或改记通过。

### 证据层级与链接

`docs/evidence/open-learning/` 与 `docs/evidence/astryx-integration/` 是同层目录，均从仓库根的 `docs/evidence/` 起算。新文档所有相对链接按各自文件所在目录解析，检查目标实际可读取；具体结果写入[本轮检查记录](../evidence/open-learning/p0/document-checks.json)。

此检查不把 Markdown 当网站启动，不冒称浏览器点击验收；本地链接可读也不代表外链已经复核。AGPL 条文核对见 D04 决策记录，本轮其他许可的官方来源与失败／更正记录见最新核对报告；不把早先未访问的外链改记为通过。没有顺带修复历史文档内部其他失效指针。
