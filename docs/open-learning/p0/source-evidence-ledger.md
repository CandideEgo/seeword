## 3. 2026-11-14 原始来源与条件复核

用户本次选择 E01 作为内部起点。通过 web-search 的 extract 读取 Commons 原片页与 [CC BY-SA 4.0 法律文本](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en)，未下载或播放视频、未读取 TimedText 字幕、未向模型提交包正文。Commons 提取页页尾标识 `oldid=1162038555`；这是该次提取页的版本标识，不冒充媒体字节哈希或另行 API 验证。

核对结果：

- 原片页 Summary 记载作者 Bodhisattwa、来源 Own work、日期 2016-06-23；Licensing 明确 CC BY-SA 4.0，与包内媒体权利声明相符。页面声明不是对所有潜在第三方权利的保证。
- 许可第 2(a)(1) 节允许在条件下复制、分享和改编；第 3(a) 节要求保留适用的作者／许可／免责声明／来源信息并说明改动；第 3(b) 节约束分享改编内容的许可及附加限制。使用既有 CC BY-SA 4.0 作为本包内容许可，不随应用代码选型改发 AGPL。
- 包内 `provenance` 和 SLCS 许可页已有作者、来源、许可链接及转录／时间标注／简中译文／词汇注释的改动说明。这里只确认信息存在与上游声明的对应关系，不证明所有展示面已正确呈现，也不证明转录、对齐、译文和答案准确。
- 许可第 2(b) 节不授予商标、隐私等其他权利；第 2(a)(5) 节禁止施加限制接收者许可权利的额外条件或有效技术措施。现有站点鉴权不因本次复核取消，但不能把它描述成可撤销接收者既有 CC 许可的依据。
- 原片许可提供分享／改编的依据，但不同交付面的实际履行仍需核对。模型披露还涉及服务条款、保留方式、隐私及具体上下文，本轮未授权该用途；不声称开放许可一概禁止模型使用。

[本次来源证据](../../evidence/open-learning/p0/e01-source-review-2026-11-14.json)记录提取文本 SHA-256、来源标识、包与许可页哈希、实际计数及未验证项。下载正文各存于仓库外发范围之外的独立 `.references/` 隔离子目录，只作本地取证，不执行其内容。最初证据快照保持不变。
